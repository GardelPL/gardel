
Rust is the ideal implementation language for gardelc: it matches the Bend ecosystem tooling, provides algebraic enums that map 1:1 to Compiler ASTs, and includes mature parser crates (logos, chumsky, or hand-rolled recursive descent) and CLI diagnostic libraries (ariadne, serde_json).   Below is a complete, working Phase 0 Compiler (gardelc-p0) written in Rust. It parses the core Gardel v0.4 syntax (module, representation, create, specify, feature, require, variant, do, let, match, ensure) and emits two targets:tree.dfy (Dafny): Translates contracts, U64 overflow bounds (newtype U64 = x: int | 0 <= x < 0x1_0000_0000_0000_0000), ghost specify functions (function), runtime feature methods (function method), and forall quantifiers so Dafny + Z3 discharges every proof obligation automatically.   tree.c (Portable C11 + Fork-Join / BendRT-style execution): Erases all specify blocks and contracts, lowers ADTs to tagged C structs, and compiles independent let bindings (let ml = l.max_value; let mr = r.max_value) into parallel fork-join tasks.
